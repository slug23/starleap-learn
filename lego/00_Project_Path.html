Self-Paced Project Path

You need: a LEGO SPIKE Prime set and the SPIKE App Python editor.

Each pair works through projects in order. Pick up where you left off every time.

Do not rush to a finished program. Build a small working piece, run it, change one thing, run again, then show the teacher what changed.

Most Pairs Start Here

Most pairs already finished early hub work, so start at Project 01 Part 3 unless they need the full ramp.

  1. Project 01: Hub Signal Board
  2. Project 02: One Motor Mini Machine
  3. Project 03: Hopper Driver
  4. Project 04: LEGO Bin Rectangle

Teacher Check For Every Project

Before getting the next project, show:

  • the robot or hub working
  • one line you changed
  • what that line controls
  • one problem you fixed or one number you tuned

Smart Bike Project Route

Keep the same Bike and Biker build for this route. Earlier project numbers have stayed the same so saved programs and printed packets still match.

  1. Project 19: Speed Modes - select a setting and make one short ride.
  2. Project 20: Trip Computer - measure your bike and calculate rides in centimetres.
  3. Project 17: Slope Lab - calibrate tilt, then let a gentle slope choose movement.
  4. Project 21: Security Alarm - use the parked bike's tilt and an armed state.
  5. Project 22: Route Data Recorder - save a list of readings and compare routes.

Projects 21 and 22 are independent choices after Project 17. Finish Project 03 and Project 09 before starting Speed Modes. Building, stationary tests and riding may take separate sessions.
