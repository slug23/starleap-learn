17. Remove From A List: Which Turtle Leaves?

Continue from Lesson 12's group_controls.py. Save a copy as turtle_removal.py. This lesson uses pop to take a turtle out of the group. Lesson 14's return values can help you read what pop gives back.

Step 1 - Notice What Is Still In The Group

Run your copy. Click three different places to add turtles. Press s to stop them. The list remembers the order you added them, even when their positions on screen change. Predict: Which turtle is turtles[0]? Which is turtles[-1]?

A list index describes order in the list, not a turtle's screen position. The newest turtle is at the end. -1 means the last item.

Step 2 - Remove The Newest

Add this function just before tick().

CODE
def remove_newest():
    if len(turtles) == 0:
        print('No turtles to remove')
        return
    leaving = turtles.pop()
    leaving.hideturtle()
    print('Turtles left:', len(turtles))

Connect the Delete key near your other screen.onkey lines.

CODE
screen.onkey(remove_newest, 'Delete')

Run the program. Add three turtles in separate places, stop them, click the Turtle window, and press and release Delete. The last one you added should disappear. Press Delete until the list is empty, then press it once more. The program should keep running.

pop() changes the list and returns the removed turtle. hideturtle() hides that object on the screen. Removing only the list reference would leave a visible turtle behind.

Step 3 - Remove The Oldest

Add this function after remove_newest().

CODE
def remove_oldest():
    if len(turtles) == 0:
        print('No turtles to remove')
        return
    leaving = turtles.pop(0)
    leaving.hideturtle()
    print('Turtles left:', len(turtles))

Connect it to o.

CODE
screen.onkey(remove_oldest, 'o')

Run the program. Add one turtle on the left, then two others at different spots. Press o. The first turtle you added should leave. Which turtle is turtles[0] now? Try pressing o with an empty group.

pop(0) removes the first item. Every later item shifts one index toward zero. The surviving turtle objects do not move on the screen because of that shift.

Step 4 - Try The List Without Graphics

Create a small file named pop_practice.py and run it.

CODE
names = ['A', 'B', 'C']
print(names.pop())
print(names)
print(names.pop(0))
print(names)

Predict the four printed lines first. Explain why the first call returns C and the second returns A. Both calls change the same list.

Step 5 - Remove A Random Member

Your program already imports random. Add a third function after remove_oldest().

CODE
def remove_random():
    if len(turtles) == 0:
        print('No turtles to remove')
        return
    index = random.randrange(len(turtles))
    leaving = turtles.pop(index)
    leaving.hideturtle()
    print('Removed index:', index)
    print('Turtles left:', len(turtles))

Connect it to r.

CODE
screen.onkey(remove_random, 'r')

Run the program. Add several turtles, stop them, then press r one time. Compare the printed index with the turtle that disappeared. Repeat with fresh groups. randrange(len(turtles)) picks a valid index from 0 through len(turtles) - 1. The empty-list check must happen first because there is no valid index when the list is empty.

Step 6 - Keep One Timer

None of the three removal functions calls tick(). The original timer keeps moving the survivors. Press g after removing a turtle: only current list members should move. The hidden turtle no longer receives movement commands.

If Delete seems ignored, click the Turtle window and press and release the key. You can bind n to remove_newest too if your keyboard sends a different Delete key name.

Final File Check

Your file should have one global turtles = [], one tick() definition, and one tick() call near the bottom. Keep the original click, space, arrow, color, stop, and go controls. Put the three new functions before tick() and the three new key connections before the call to tick().

Run one final experiment: add four turtles, stop them, remove one with each key, then press g. Only the survivor should move. If a turtle stays visible after removal, check that the matching function calls leaving.hideturtle().

Teacher Check

Show three turtles. Remove the newest, then the oldest. Point to the two pop calls and explain which item each returns. Show that removing from an empty list does not crash. Explain why the function also calls hideturtle().
