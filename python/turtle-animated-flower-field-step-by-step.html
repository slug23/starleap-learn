13. Animated Flower Field: Redraw A New Frame

Continue after Lesson 12, Group Controls. Moving a turtle's picture changes where it appears, but turning the turtle does not turn ink it already drew. To animate a flower, we will erase its old drawing and draw it again from a new starting angle.

Step 1 - Draw One Familiar Flower

Save a new file named animated_flowers.py. Type this starter program. It uses the two-arc petal from the earlier flower lessons.

CODE
import random
import turtle

screen = turtle.Screen()
screen.setup(600, 800, 0, 0)
screen.tracer(0)

flower = turtle.Turtle()
flower.hideturtle()
flower.color('teal')

def draw_flower(pen, radius):
    for i in range(6):
        pen.circle(radius, 60)
        pen.left(120)
        pen.circle(radius, 60)
        pen.left(180)

draw_flower(flower, 50)
screen.update()
screen.mainloop()

Run the program. You should see one flower appear as a complete picture.

pen is a meaningful parameter name: it tells the function which turtle will draw. We pass flower, the turtle itself, just as we previously passed numbers and colors to functions.

The turns produce six petals around one center. Each petal returns to its starting position. All six together return to the starting heading, ready for another drawing.

Step 2 - Turn The Turtle, Not The Ink

Add a turn after drawing the flower, before the update.

EDIT VIEW - Gray = already there; dark = add or change
draw_flower(flower, 50)
flower.left(15)
screen.update()
screen.mainloop()

Run the program. The flower picture has not rotated. The hidden turtle now faces a different direction, but the old ink stays where it was drawn.

Step 3 - Draw From The New Heading

Add a second drawing call after the turn.

EDIT VIEW - Gray = already there; dark = add or change
draw_flower(flower, 50)
flower.left(15)
draw_flower(flower, 50)
screen.update()
screen.mainloop()

Run the program. You see both flowers on top of each other. The second one starts at a different angle.

Now clear the old drawing before the turn and second drawing.

EDIT VIEW - Gray = already there; dark = add or change
draw_flower(flower, 50)
flower.clear()
flower.left(15)
draw_flower(flower, 50)
screen.update()
screen.mainloop()

Run the program. Only the rotated flower remains. There was no update between the first drawing and clearing it, so that first drawing was never displayed as a frame.

flower.clear() removes this turtle's ink, but keeps its position, heading, and color. Do not use screen.clear() here: it clears the screen and resets screen settings and event connections too.

Step 4 - Save A Starting Angle For One Frame

Replace everything from the first draw_flower(flower, 50) call through screen.update() with the function and startup below. Keep the definition of draw_flower above it.

EDIT VIEW - Gray = already there; dark = add or change
        pen.left(180)

def tick():
    starting_angle = flower.heading()
    flower.clear()
    draw_flower(flower, 50)
    flower.setheading(starting_angle + 2)
    screen.update()

tick()
screen.mainloop()

Run the program. One flower is expected: this is still just one frame.

heading() gives the turtle's current angle. starting_angle remembers it for this call. After drawing, setheading(starting_angle + 2) prepares the angle for the next frame. The turtle object keeps that heading after the function finishes.

Step 5 - Animate The Flower

Add a timer at the end of tick().

EDIT VIEW - Gray = already there; dark = add or change
    flower.setheading(starting_angle + 2)
    screen.update()
    screen.ontimer(tick, 100)

tick()
screen.mainloop()

Run the program. The flower should rotate. Each tick clears the old flower, draws one replacement, prepares the next heading, and shows the completed frame.

Change only the + 2 to + 1. Run it. Try - 2 instead. Run it again. Restore + 2 before continuing. Small angle changes make movement easier to follow.

for x_position in [-160, 0, 160]:

    flower.hideturtle()

This loop visits three numbers, not indexes. Each becomes an x coordinate for a new flower turtle. teleport places it without drawing a travel line.

Before running, replace the whole tick() function with this version. The existing startup call stays below it.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    for flower in flowers:
        starting_angle = flower.heading()
        flower.clear()
        draw_flower(flower, 50)
        flower.setheading(starting_angle + 2)
    screen.update()
    screen.ontimer(tick, 100)

tick()
screen.mainloop()

Run the program. All three flowers rotate. The loop clears and redraws each flower using its own turtle. The update is outside the loop, so one frame shows the finished group.

colors = ['red', 'gold', 'teal', 'purple']

    flower = turtle.Turtle()

    x_position = random.randint(-210, 210)
    y_position = random.randint(-290, 290)
    flower.teleport(x_position, y_position)

Make the flowers smaller by changing the drawing call inside tick().

    for flower in flowers:

        draw_flower(flower, 30)
        flower.setheading(starting_angle + 2)

Run the program. The flowers keep their positions and colors while rotating. Some overlap; restart to try another arrangement.

Random choices happen once during setup. The timer redraws the flowers we already have. If we chose a new position on every tick, the flowers would jump around instead of rotating in place.

Step 8 - Compare Trails With Frames

In tick(), temporarily put # before flower.clear() to make it a comment. Run briefly, then close the window.

The new drawings now pile up into a pattern. Remove the # and run again to restore the rotating field. Clearing old ink is part of this animation; it was not needed when we only moved pen-up turtle pictures.

Make It Yours

Choose one experiment: change the number of flowers, the petal radius, the angle change, or the timer delay. Predict its effect, then run and compare.

Teacher Check
