18. Lost Turtles: Leave The Safe Zone

Open your finished turtle_removal.py from Lesson 15 and save a copy as lost_turtles.py. Turtles that wander outside a box will leave the group automatically. You can still add turtles with a click or the space bar.

Step 1 - Draw A Visible Safe Zone

The window is 600 by 800. We will use a smaller box so there is room to see a turtle cross its edge. Add these numbers below step_size = 3.

CODE
LIMIT_X = 220
LIMIT_Y = 320

Add this function just before add_turtle().

CODE
def draw_boundary():
    border = turtle.Turtle()
    border.hideturtle()
    border.penup()
    border.teleport(-LIMIT_X, -LIMIT_Y)
    border.pendown()
    for side in range(2):
        border.forward(2 * LIMIT_X)
        border.left(90)
        border.forward(2 * LIMIT_Y)
        border.left(90)

Call it once just before tick() at the bottom.

CODE
draw_boundary()
tick()

Run the program. You should see a rectangle inside the window. The border turtle is deliberately not appended to turtles, so group keys cannot move or remove it.

Step 2 - Ask Whether One Turtle Is Inside

Add this function before tick().

CODE
def is_inside(member):
    return (-LIMIT_X <= member.xcor() <= LIMIT_X
            and -LIMIT_Y <= member.ycor() <= LIMIT_Y)

Predict: Is a turtle exactly on the line inside? Is one just beyond it inside? and requires both its horizontal and vertical positions to be in range. The function returns True or False.

Step 3 - Notice A Turtle Leaving

Inside tick(), add a check just after moving each member.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    for member in turtles:
        member.forward(step_size)
        if not is_inside(member):
            print('A turtle crossed the boundary')
    screen.update()

Run the program. Click near the right edge of the box, turn the turtle toward that edge, and press g if the group was stopped. Watch the message repeat after it crosses. Checking a condition does not remove anything yet.

Step 4 - Collect The Lost Turtles

Replace the tick() function with this version. Read the two loops before running it.

CODE
def tick():
    lost = []
    for member in turtles:
        member.forward(step_size)
        if not is_inside(member):
            lost.append(member)
    for member in lost:
        turtles.remove(member)
        member.hideturtle()
    if lost:
        print('Lost:', len(lost), 'Still here:', len(turtles))
    screen.update()
    screen.ontimer(tick, 100)

Run the program. Add two turtles near an edge and steer them out. Both should disappear, the count should drop, and the remaining turtles should keep moving. lost is a new temporary list for this frame. remove(member) removes that particular object from turtles.

Why Two Loops?

The first loop visits the current group and writes down who crossed the line. The second loop changes the group. If you remove an item from turtles during the first loop, later items shift left and the loop can skip one. This is easiest to notice when two turtles leave in the same frame.

A click outside the safe zone adds a turtle; the next frame removes it. Try it and explain why. Press Delete, o, or r after some turtles leave: the old removal keys still work with the smaller list.
