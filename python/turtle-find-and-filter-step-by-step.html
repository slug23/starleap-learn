19. Find And Filter: Choose Turtles By A Rule

Open your finished lost_turtles.py from Lesson 16 and save a copy as turtle_search.py. A list is useful for more than moving every member. You can search it, count members that meet a rule, and keep a selected group.

Step 1 - Count Turtles On The Right

Add this function before tick().

CODE
def count_right():
    count = 0
    for member in turtles:
        if member.xcor() > 0:
            count += 1
    print('Right side:', count, 'Total:', len(turtles))

Connect the k key with the other key connections.

CODE
screen.onkey(count_right, 'k')

Run the program. Press s, add turtles on both sides of the vertical middle, then press k. Predict the count before you read it. A turtle at x = 0 is not on the right because the test uses >.

Step 2 - Find The Nearest Turtle To A Click

Add this function before tick().

CODE
def highlight_nearest(x, y):
    if len(turtles) == 0:
        print('No turtle to find')
        return
    nearest = turtles[0]
    best_distance = nearest.distance(x, y)
    for member in turtles:
        distance = member.distance(x, y)
        if distance < best_distance:
            nearest = member
            best_distance = distance
    nearest.color('orange')
    print('Nearest distance:', round(best_distance))

For this experiment, change the click connection at the bottom from screen.onclick(add_turtle) to:

CODE
screen.onclick(highlight_nearest)

Run the program. Use space to add several turtles, press s, and click close to one of them. It should turn orange. Click between two turtles. A search starts with one candidate, then replaces it only when it finds a closer one. It also works when there is just one turtle.

Step 3 - Keep Adding By Click

Restore the click connection to screen.onclick(add_turtle). Connect highlight_nearest to a different mouse button so you can still add turtles with the usual left click.

CODE
screen.onclick(add_turtle)
screen.onclick(highlight_nearest, btn=3)

Run the program. Left click to add; right click near one to highlight it. On a trackpad, use its secondary-click gesture. If secondary click is unavailable, use space to add during Step 2 and keep the single click connection for finding.

Step 4 - Keep Only The Orange Turtles

Add this function before tick().

CODE
def keep_orange():
    leaving = []
    for member in turtles:
        if member.pencolor() != 'orange':
            leaving.append(member)
    for member in leaving:
        turtles.remove(member)
        member.hideturtle()
    print('Kept:', len(turtles), 'Removed:', len(leaving))

Connect it to f.

CODE
screen.onkey(keep_orange, 'f')

Run the program. Add four turtles, stop them, and right click near two to turn them orange. Press f. Only orange turtles should remain. Try f again, then add a new turtle and try it once more.

This is filtering: keep the members that match a rule. Like Lesson 16, we first collect the ones that should leave, then change the main list in a second loop.

Step 5 - Change The Rule

Make a copy of your file. Change 'orange' in keep_orange() to 'teal'. Press c to color the current group teal, then add a new turtle and press f. Predict which turtles survive. The same loop can implement a new rule by changing its condition.
