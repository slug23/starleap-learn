19. Find And Filter: Choose Turtles By A Rule

Open your finished lost_turtles.py from Lesson 18 and save a copy as turtle_search.py. A list is useful for more than moving every member. You can search it, count members that meet a rule, and keep a selected group.

Step 1 - Count Turtles On The Right

Add this function before tick().

CODE
def count_right():
    count = 0
    for member in turtles:
        if member.xcor() > 0:
            count += 1
    print('Right side:', count, 'Total:', len(turtles))

Connect the k key with the other key connections.

CODE
screen.onkey(count_right, 'k')

Run the program. Press s, add turtles on both sides of the vertical middle, then press k. Predict the count before you read it. A turtle at x = 0 is not on the right because the test uses >.

Step 2 - Find The Nearest Turtle To A Click

Add this function before tick().

CODE
def highlight_nearest(x, y):
    if len(turtles) == 0:
        print('No turtle to find')
        return
    nearest = turtles[0]
    best_distance = nearest.distance(x, y)
    for member in turtles:
        distance = member.distance(x, y)
        if distance < best_distance:
            nearest = member
            best_distance = distance
    nearest.color('orange')
    print('Nearest distance:', round(best_distance))

For this experiment, change the click connection at the bottom from screen.onclick(add_turtle) to:

CODE
screen.onclick(highlight_nearest)

Run the program. Use space to add several turtles, press s, and click close to one of them. It should turn orange. Now click near a different turtle. What happens to the first orange turtle? Try a third click. The search finds a new nearest turtle each time, but this code never changes an earlier choice back to black.

Step 3 - Reset The Whole Group

First try the straightforward fix. Replace nearest = turtles[0] with these lines. Keep the rest of highlight_nearest() the same.

CODE
    for member in turtles:
        member.color('black')
    nearest = turtles[0]

Run again and click near several different turtles. Each click makes every turtle black before the search turns the new nearest turtle orange. This fixes the problem, but it changes the color of every turtle on every click.

Step 4 - Remember The Orange Turtle

We can remember the last choice instead. Replace your whole highlight_nearest() function with the block below. The nearest = None line goes above the function, outside it. global nearest lets the function update that remembered turtle for the next click.

CODE
nearest = None

def highlight_nearest(x, y):
    global nearest
    if len(turtles) == 0:
        nearest = None
        print('No turtle to find')
        return
    if nearest not in turtles:
        nearest = turtles[0]
        nearest.color('orange')
    best_distance = nearest.distance(x, y)
    for member in turtles:
        distance = member.distance(x, y)
        if distance < best_distance:
            nearest.color('black')
            nearest = member
            best_distance = distance
            nearest.color('orange')
    print('Nearest distance:', round(best_distance))

Run again. Click near different turtles. Before the search replaces nearest, it turns the old choice black; then it turns the new choice orange. At each point in the search, only the current best choice is orange. If that turtle was removed from the list, the next click starts with turtles[0] instead. Predict what happens when you click near the same turtle twice.

Step 5 - Keep Adding With Space

On a MacBook trackpad, keep one job for an ordinary click: finding the nearest turtle. Use the Space key to add another turtle at the center. Check that these connections appear once at the bottom of your file; the Space connection came from Lesson 11.

CODE
screen.listen()
screen.onkey(add_at_center, 'space')
screen.onclick(highlight_nearest)

Run the program. Press Space to add a turtle, let it move away from the center, then press Space again. Use an ordinary trackpad click near either turtle to highlight it. You do not need a secondary-click gesture.

Step 6 - Keep Only The Orange Turtle

Add this function before tick().

CODE
def keep_orange():
    leaving = []
    for member in turtles:
        if member.pencolor() != 'orange':
            leaving.append(member)
    for member in leaving:
        turtles.remove(member)
        member.hideturtle()
    print('Kept:', len(turtles), 'Removed:', len(leaving))

Connect it to f.

CODE
screen.onkey(keep_orange, 'f')

Run the program. Press Space four times, allowing the turtles to spread out, then press s to stop them. Click near two different turtles. Only the most recently selected turtle should be orange. Press f: that one turtle should remain. Try f again, then press Space to add a new turtle and try it once more.

This is filtering: keep the members that match a rule. Like Lesson 18, we first collect the ones that should leave, then change the main list in a second loop.

Step 7 - Change The Rule

Make a copy of your file. Change 'orange' in keep_orange() to 'teal'. Press c to color the current group teal, then add a new turtle and press f. Predict which turtles survive. The same loop can implement a new rule by changing its condition.
