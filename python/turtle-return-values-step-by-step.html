14. Return Values: Make A Random Color

Your functions have drawn shapes and moved turtles. Now a function will give a value back to the code that called it. You will use that value to set a turtle's color.

Step 1 - A Function That Gives An Answer

Save a new file named return_colors.py. Start with this small program, without a turtle window yet.

CODE
def make_color():
    return 'red'

ink = make_color()
print(ink)

Predict: What will the last line print? Run the program and check.

The call make_color() runs the function. return 'red' ends that call and sends the text 'red' back. The assignment stores that returned value in ink. Then print(ink) displays it.

The function does not print anything itself. Its job is to supply a value that the caller can use. return ends the function immediately; any work the function needs to do must come before it.

Step 2 - Printing Is Not Returning

Temporarily replace the return line with a print line. Keep the two lines at the bottom.

EDIT VIEW - Gray = already there; dark = add or change
def make_color():
    print('red')

ink = make_color()
print(ink)

Predict: There are now two print calls. What will each display?

Run the program. You should see red, then None.

The function printed red, but it did not return a color. A function that reaches its end without a return value gives back None. That is what ink received and the last line printed.

Restore the return line before continuing.

EDIT VIEW - Gray = already there; dark = add or change
def make_color():
    return 'red'

ink = make_color()
print(ink)

Run the program. You should see just red again. We need a returned value because the turtle cannot use a message that was only printed.

Step 3 - Let The Turtle Use The Answer

At the very top of the same file, insert the import and turtle setup before the function definition.

EDIT VIEW - Gray = already there; dark = add or change
import turtle

screen = turtle.Screen()
screen.setup(600, 800, 0, 0)
t = turtle.Turtle()
t.shape('turtle')
t.penup()
t.speed(5)

def make_color():
    return 'red'
...

Add these lines after the existing print(ink), at the left edge. Keep screen.mainloop() last.

EDIT VIEW - Gray = already there; dark = add or change
ink = make_color()
print(ink)
t.color(ink)
t.dot(40)
t.forward(60)

screen.mainloop()

Run the program. You should see a red dot and a red turtle beside it. The same returned value was printed and used as a color.

make_color() supplies the color. t.color(ink) applies it. These are separate jobs: returning a color does not change the turtle until the caller uses it.

Step 4 - Return An RGB Color

RGB means red, green, and blue. We will mix amounts of these three colors of light. Add this setting after the screen setup so each amount can be a whole number from 0 through 255.

EDIT VIEW - Gray = already there; dark = add or change
screen.setup(600, 800, 0, 0)
screen.colormode(255)
t = turtle.Turtle()
...

Replace the function's return 'red' line with these four lines.

EDIT VIEW - Gray = already there; dark = add or change
def make_color():
    red = 40
    green = 160
    blue = 220
    return (red, green, blue)

ink = make_color()
...

Run the program. The output is (40, 160, 220), and the turtle uses that mix. The parentheses and commas group the three amounts into one value called a tuple. The function returns that one tuple; ink holds it, and t.color(ink) accepts it.

Keep the order red, green, blue. 0 means none of that channel; 255 means its full amount. You do not need to unpack the tuple to give it to the turtle.

Step 5 - Randomize One Channel

Add the random import above the turtle import.

EDIT VIEW - Gray = already there; dark = add or change
import random
import turtle
...

Change only the red assignment inside the function.

EDIT VIEW - Gray = already there; dark = add or change
def make_color():
    red = random.randint(0, 255)
    green = 160
    blue = 220
    return (red, green, blue)

Run the program a few times, closing the turtle window between runs. Compare the printed tuples. The first amount can change; green and blue stay fixed. The color may change too.

random.randint(0, 255) already returns a value. You are using its answer as the red amount inside your own function.

Step 6 - Randomize All Three Channels

Change the other two assignments too. Keep the return line below all three choices, inside the function.

EDIT VIEW - Gray = already there; dark = add or change
def make_color():
    red = random.randint(0, 255)
    green = random.randint(0, 255)
    blue = random.randint(0, 255)
    return (red, green, blue)

Run the program several times. All three amounts can now vary. Some colors will be pale or hard to see against white; the printed tuple lets you inspect them. Random choices can repeat.

red, green, and blue are local variables in this function. Returning their tuple makes the result available to the caller as ink; you do not need global variables for these channels.

Step 7 - Reuse The Returned Color

Add another dot after the forward movement. Do not call make_color() again yet.

EDIT VIEW - Gray = already there; dark = add or change
t.color(ink)
t.dot(40)
t.forward(60)
t.dot(40)

screen.mainloop()

Predict: Will the second dot have a new random color?

Run the program. Both dots use the same color. You called the function once and applied its answer once. Moving and drawing again do not call the function for you.

Step 8 - Ask For Another Color

Insert these lines between the movement and the second dot.

EDIT VIEW - Gray = already there; dark = add or change
t.forward(60)
ink = make_color()
print(ink)
t.color(ink)
t.dot(40)

screen.mainloop()

Run the program. Two tuples print, and the dots can have different colors. The new call runs all three random choices again and returns a new tuple. Reassigning ink stores the new answer; it does not recolor the first dot.

Step 9 - A Row Of Random Colors

Replace all the code below the function definition, from the first ink = make_color() through the second dot, with this loop. Keep screen.mainloop() last.

EDIT VIEW - Gray = already there; dark = add or change
    return (red, green, blue)

t.teleport(-210, 0)
for i in range(8):
    ink = make_color()
    print(ink)
    t.color(ink)
    t.dot(40)
    t.forward(60)

screen.mainloop()

Run the program. You should see eight dots, with a fresh color choice for each. Trace one pass: call the function, receive the tuple, store it, print it, use it, draw, and move.

Try It Yourself

Make all eight dots share one randomly chosen color. Use the lesson about choosing once before a loop versus choosing inside it. Keep the function returning a value.

Challenge: In a copy of your keyboard drawing program, make a key use this RGB function to change the turtle's color. Use the keyboard lesson for the event connection and remember the screen's color mode. Your color function should return a color; let the keyboard function decide how to use it.

Teacher Check

Point to the function definition, its return line, a call, and the variable that receives its answer. Explain how return differs from print.

Show the three RGB amounts and explain why they are returned together. Explain why drawing twice did not choose twice until you added another function call.

If the output contains None, check that your function returns the tuple. If Python reports a bad color sequence, check screen.colormode(255) and that all three amounts are between 0 and 255.
