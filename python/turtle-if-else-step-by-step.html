15. Conditions: Choose A Turtle Path

A condition lets your program choose what to do. First try the choice in the console, then make a turtle show the result.

Step 1 - Ask A True Or False Question

Save a new file named choose_path.py. Type and run this program.

CODE
steps = 8
print(steps > 5)
print(steps < 5)

Predict both lines before you run. You should see True and False. A comparison produces a Boolean value: either true or false. > means greater than; < means less than.

Step 2 - Run Code Only When The Condition Is True

Add this code at the bottom of the file.

EDIT VIEW - Gray = already there; dark = add or change
print(steps < 5)
if steps > 5:
    print('long path')
print('finished')

Run it. After the two Boolean values, you should see long path, then finished. The indented line belongs to the if block. The last line is outside it and always runs. Change steps to 3 and run again: long path disappears, but finished remains.

Step 3 - Give The Other Case A Job

Replace the if block with this one. Keep the final print line.

EDIT VIEW - Gray = already there; dark = add or change
print(steps < 5)
if steps > 5:
    print('long path')
else:
    print('short path')
print('finished')

Run with steps = 3, then with steps = 8. Exactly one path message appears each time. else has no condition: it handles every case where the if condition is false. Keep the colon and four spaces of indentation.

Step 4 - Draw The Choice

Save a separate file named turtle_choice.py. Type the complete program.

CODE
import turtle

screen = turtle.Screen()
screen.setup(600, 600, 0, 0)
artist = turtle.Turtle()
artist.shape('turtle')

steps = 8
if steps > 5:
    artist.pencolor('blue')
    artist.forward(160)
else:
    artist.pencolor('orange')
    artist.left(90)
    artist.forward(80)

screen.mainloop()

Predict the color and direction. Run it and check. Change steps to 3 and run again. The turtle now takes the other path. The code inside each branch runs in order; the unused branch is skipped.

Step 5 - Check The Boundary

Change only the assignment to steps = 5. Predict which path the turtle takes, then run. It takes the orange path because 5 > 5 is false. Change the comparison to steps >= 5 and run again. >= means greater than or equal to, so the blue path now runs.

Try steps = 4, 5, and 6. Tell your teacher which color each value draws and why. Show both branches running on your screen.
