12. Group Controls: One Key, Every Turtle

Continue after Lesson 11, Lists. Your global list already lets one tick reach every turtle. Now your own keyboard functions will use that same list.

Step 1 - Keep A Working Copy

Open the finished turtle_group.py from Lesson 11. Save a copy named group_controls.py. Run it once: clicks and the space bar should add turtles, and the turtles should wander.

Inside tick(), delete the turn_degrees = random.randint(-30, 30) line. Replace member.left(turn_degrees) with member.left(5) so the loop uses a fixed small turn.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    for member in turtles:
        member.left(5)
        member.forward(3)
    screen.update()
    screen.ontimer(tick, 100)

Run the program. Add a few turtles in different places. They should now follow small circular paths, making the next experiments easier to watch.

def add_at_center():

def turn_all_left():
    for member in turtles:
        member.left(30)

def tick():
    ...

Connect it at the bottom.

EDIT VIEW - Gray = already there; dark = add or change
screen.onkey(add_at_center, 'space')
screen.onkey(turn_all_left, 'Left')
tick()
screen.mainloop()

Run the program. Add three turtles. Press and release Left. All three turn an extra 30 degrees. Add another turtle, then press Left again. It joins in because the function visits the list as it exists when the key is released.

The keyboard function changes their headings. The next timed frame shows those changes. We keep the timer in tick() only.

Step 3 - Give The Keyboard The Turning Job

Delete the member.left(5) line inside tick(). The loop should now contain only the forward movement.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    for member in turtles:
        member.forward(3)
    screen.update()
    screen.ontimer(tick, 100)

Run the program. The turtles move straight until you press Left. Make several turns before they leave the window. Restart if you need a fresh group.

The timer controls when they move. Your keyboard function controls where they face. Two different events can work with the same turtles.

Add a shared number immediately after the global list.

turtles = []
step_size = 3

def add_turtle(x, y):
    ...

Use it inside tick() in place of 3.

Step 7 - Stop And Go

Add two functions between color_all() and tick().

EDIT VIEW - Gray = already there; dark = add or change
        member.color('teal')

def stop_all():
    global step_size
    step_size = 0

def go_all():
    global step_size
    step_size = 3

def tick():
    ...

global step_size says that the assignment changes the variable created outside the functions. Without it, step_size = 0 would create a local variable inside stop_all, leaving the shared movement distance unchanged.

This differs from turtles.append(...): append changes the contents of the existing list; these assignments replace the value stored under a shared name.

Connect both keys after the c connection.

EDIT VIEW - Gray = already there; dark = add or change
screen.onkey(color_all, 'c')
screen.onkey(stop_all, 's')
screen.onkey(go_all, 'g')
tick()
screen.mainloop()

Run the program. Press s to stop forward movement. While stopped, turn, change colors, and add turtles. Press g to move again. Stop and go several times: the turtles should resume at the same speed each time.

The timer is still running while the distance is zero. That keeps frames updating. Neither key starts another timer.

Make Your Own Group Commands

Keep the working program. Choose one goal, build it, and run it before trying another. These are challenges: use the earlier lessons to decide what code you need.

  • Make a key lift every turtle's pen and another key lower every pen.
  • Make a key choose one random color for the entire group.
  • Make a different key choose a separate random color for each turtle.
  • Make a key turn every turtle around.

Think ahead: For the two random-color challenges, where would you make the random choice so it happens once for the group, or once for each member?

Teacher Check

Show a command working with two turtles. Add two more, then show the same command working with four.

Point to the list that both the keyboard functions and tick() use. Explain why the movement continues even when no key is pressed.

Show stop and go. Explain why assigning step_size needs global here but appending to turtles does not. Explain why calling tick() from the go function would start an unwanted extra timer chain.

If a key seems ignored, click the turtle window and check screen.listen(). Check the spelling and capitalization of the key name. For onkey, press and release the key; holding it down is not the same as repeated releases.
