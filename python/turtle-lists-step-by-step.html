11. Lists: A Growing Group Of Turtles

Continue after Lesson 10, Animation. You will first explore a list without graphics. Then you will keep turtles in a list, visit them with a loop, and add new turtles with events.

Step 1 - Look Inside A List

Save a small new file named list_practice.py. Type this program.

CODE
colors = ['red', 'gold', 'teal']
print(colors)
print(len(colors))
print(colors[0])
print(colors[1])

Predict: What will each line print? Run the program and check.

The square brackets hold a list of items. len(colors) counts its items. An index selects one item: index 0 is first, index 1 is second. This list has three items, with indexes 0, 1, and 2.

Step 2 - Add One Item

Add these lines at the bottom of the same file.

EDIT VIEW - Gray = already there; dark = add or change
print(colors[1])
colors.append('blue')
print(colors)
print(len(colors))

Run the program. The original items are still there, with blue at the end. append changes the existing list. Write it on its own line, without colors = in front.

Step 3 - Visit Each Item

Add this loop at the very bottom, after the new print(len(colors)) line.

EDIT VIEW - Gray = already there; dark = add or change
colors.append('blue')
print(colors)
print(len(colors))
for color in colors:
    print(color)
print('done')

Run the program. The loop prints one color per pass, then prints done once.

range(4) would give the loop numbers. colors gives it the items themselves. color is a variable holding the current item; its name is your choice.

Step 4 - Put One Turtle In A List

Save a separate new file named turtle_group.py. Keep the practice file for reference. Type this whole starter program.

CODE
import random
import turtle

screen = turtle.Screen()
screen.setup(600, 800, 0, 0)
screen.tracer(0)
turtles = []

new_turtle = turtle.Turtle()
new_turtle.shape('turtle')
new_turtle.penup()
turtles.append(new_turtle)
print(len(turtles))

screen.update()
screen.mainloop()

Run the program. You should see one turtle and the number 1 in the output.

[] starts an empty list. A list can hold turtle objects as well as colors or numbers. append keeps a reference to this turtle; it does not make a second turtle.

Step 5 - A Function That Adds A Turtle

Replace the five lines from new_turtle = turtle.Turtle() through print(len(turtles)) with this function and its call.

EDIT VIEW - Gray = already there; dark = add or change
turtles = []

def add_turtle(x, y):
    new_turtle = turtle.Turtle()
    new_turtle.shape('turtle')
    new_turtle.penup()
    new_turtle.teleport(x, y)
    turtles.append(new_turtle)
    print(len(turtles))

add_turtle(0, 0)
screen.update()
screen.mainloop()

Run the program. It should look the same. Add a second call, add_turtle(100, 0), just after add_turtle(0, 0). Run again: two calls create two separate turtles.

turtles is a global list because it is created at the left edge, outside the functions. new_turtle is local to each function call. The list keeps each turtle available after that call ends.

We do not need a global turtles statement to append to the existing list. We are changing its contents, not assigning a different list to the name. Keep turtles = [] outside the function so adding a turtle does not reset your group.

Step 6 - Move Every Turtle Once

Add this function below add_turtle, before the two calls at the bottom.

EDIT VIEW - Gray = already there; dark = add or change
    print(len(turtles))

def tick():
    for member in turtles:
        member.left(5)
        member.forward(3)
    screen.update()

add_turtle(0, 0)
...

Replace the bottom screen.update() with tick().

EDIT VIEW - Gray = already there; dark = add or change
add_turtle(0, 0)
add_turtle(100, 0)
tick()
screen.mainloop()

Run the program. Both turtles turn left 5 degrees and move forward 3 steps. They start in different places, but make the same movement. member holds an actual turtle from the list, not its index.

The turn and move are indented eight spaces: they belong to the loop inside the function. screen.update() is indented four spaces: it belongs to the function, after the loop. We move every turtle before showing the frame.

Add one timer at the end of tick().

        member.forward(3)
    screen.update()

add_turtle(0, 0)

Run the program. Watch the turtles follow matching circular paths, side by side. Each tick gives both turtles the same turn and distance, so they stay synchronized.

Step 8 - Choose One Random Turn For The Group

Add turn_degrees inside tick(), just before the for line. Indent it four spaces, the same as the for line. Then replace 5 in member.left(5) with turn_degrees.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    turn_degrees = random.randint(-30, 30)
    for member in turtles:
        member.left(turn_degrees)
        member.forward(3)
    screen.update()
    screen.ontimer(tick, 100)

Predict: The turn is random now. Will the turtles still move together?

Run the program. Both turtles wander, but stay synchronized. Each tick chooses one number before the loop starts. Every turtle uses that same number during that tick. The next tick chooses again.

Step 9 - Choose A Separate Turn For Each Turtle

Move turn_degrees = random.randint(-30, 30) from above the for line to immediately below it. Indent it eight spaces so it belongs to the loop. Remove the old copy above the loop; there should be only one assignment.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    for member in turtles:
        turn_degrees = random.randint(-30, 30)
        member.left(turn_degrees)
        member.forward(3)
    screen.update()
    screen.ontimer(tick, 100)

Predict: You moved one line without changing its calculation. Will the paths still match?

Run the program. Watch them wander separately. The random choice is inside the loop, so Python chooses again for each turtle on every tick. They can sometimes choose the same turn by chance, but no longer have to move alike.

member.left(turn_degrees) did not change. What changed was when Python assigns a new number to turn_degrees: once per tick before the loop, or once per turtle inside it.

After a while, turtles may wander off the visible area. That does not remove them from the list. Restart to bring them back while you experiment.

Step 10 - Add A Turtle Where You Click

Delete both startup add_turtle(...) calls. Put a screen-click connection in their place.

EDIT VIEW - Gray = already there; dark = add or change
    screen.ontimer(tick, 100)

screen.onclick(add_turtle)
tick()
screen.mainloop()

Run the program. It starts empty. Click in several places. Each click adds a turtle at that position; the timer moves all of them on later ticks.

A screen click supplies two arguments: its x and y coordinates. That matches add_turtle(x, y). Pass the function name without parentheses so the screen can call it later.

An empty list is safe to loop over: there are no members to move yet, but the rest of tick() still runs.

Step 11 - Add With A Key Too

Add this new function between add_turtle and tick.

EDIT VIEW - Gray = already there; dark = add or change
    print(len(turtles))

def add_at_center():
    add_turtle(0, 0)

def tick():
    ...

Add the key connection at the bottom.

EDIT VIEW - Gray = already there; dark = add or change
screen.onclick(add_turtle)
screen.listen()
screen.onkey(add_at_center, 'space')
tick()
screen.mainloop()

Run the program. Click to add turtles at chosen positions. Press and release space to add at the center. Several turtles may overlap at first, then separate as they move.

A key callback receives no coordinates. add_at_center() supplies them by calling add_turtle(0, 0). Every call still appends to the same global list.
