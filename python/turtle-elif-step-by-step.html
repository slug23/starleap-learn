16. More Conditions: Choose A Turtle Color

You have used if and else to choose between two paths. Now give the turtle three possible results, then combine two questions.

Step 1 - See A Middle Case

Save a new file named three_choices.py. Type this program.

CODE
distance = 75

if distance < 50:
    print('near')
elif distance < 100:
    print('middle')
else:
    print('far')

Predict the output and run it. Change distance to 30, then 120, running after each edit. elif means “else, if this condition is true.” Python checks from top to bottom and runs the first matching branch. If neither condition matches, else runs.

Step 2 - Test The Edges

Try distance = 50 and distance = 100. Predict before each run. 50 is middle; 100 is far. The < comparison does not include the number on its right. Change the first condition to distance <= 50, then run with 50 again. <= includes 50, so it is now near.

Restore < before the next step.

Step 3 - Let A Turtle Show The Result

Save a separate file named color_choice.py. Type the whole program.

CODE
import turtle

screen = turtle.Screen()
screen.setup(600, 600, 0, 0)
artist = turtle.Turtle()
artist.shape('turtle')
artist.penup()

distance = 75
if distance < 50:
    artist.pencolor('green')
elif distance < 100:
    artist.pencolor('gold')
else:
    artist.pencolor('red')

artist.dot(60)
screen.mainloop()

Predict the dot color and run. Try 30 and 120 too. The shared artist.dot(60) line sits outside the branches, so it runs after any of the three colors is chosen.

Step 4 - Combine Two Questions

Add active = True just before distance = 75. Replace only the first condition with this line.

EDIT VIEW - Gray = already there; dark = add or change
active = True
distance = 75
if active and distance < 50:
    artist.pencolor('green')
elif distance < 100:

Run with distance = 30 and active = True, then change active to False and run again. and needs both sides to be true. With False, the first branch is skipped and the middle branch makes a gold dot. This demonstrates why branch order matters.

Step 5 - Explain The Decision

Try distance = 49, 50, and 100 with active = True. For each, predict the color, run, and explain which branch matched. Then set active = False and distance = 30. Show your teacher the gold dot and explain why the green branch did not run.
