20. Undo One Turtle Action

Lesson 19 changed which turtles stayed in a group. This short experiment uses one drawing turtle to learn what its own undo() can reverse. It extends the skill tree's Keyboard Turtle project.

Step 1 - Draw Three Lines

Save a new file named undo_drawing.py. Type the complete program.

CODE
import turtle

screen = turtle.Screen()
LINE_LENGTH = 80
artist = turtle.Turtle()
artist.forward(LINE_LENGTH)
artist.left(90)
artist.forward(LINE_LENGTH)
artist.left(90)
artist.forward(LINE_LENGTH)

screen.mainloop()

Run it. Point to the three lines in the order they were drawn. LINE_LENGTH names the shared distance; change it once to make all three lines longer or shorter. The artist remembers recent Turtle actions in its undo buffer.

Step 2 - Undo One Action

Add one line just before screen.mainloop().

EDIT VIEW - Gray = already there; dark = add or change
artist.forward(LINE_LENGTH)
artist.undo()
screen.mainloop()

Predict what disappears, then run. The last forward move is reversed; the earlier lines remain. Add a second artist.undo() and run again. The preceding turn is reversed too. One call reverses one recorded action, not a whole project.

Step 3 - Compare With Clear

Temporarily replace both undo calls with artist.clear().

EDIT VIEW - Gray = already there; dark = add or change
artist.forward(LINE_LENGTH)
artist.clear()
screen.mainloop()

Run it. The drawing disappears, but the turtle stays at its final position and heading. Restore one artist.undo() and run again to see the difference.

Step 4 - Inspect The Buffer

Add these prints around the undo call.

EDIT VIEW - Gray = already there; dark = add or change
artist.forward(LINE_LENGTH)
print('Actions available:', artist.undobufferentries())
artist.undo()
print('After one undo:', artist.undobufferentries())
screen.mainloop()

Run and compare the two counts. The exact starting count can include setup actions, so focus on what changes after one undo. setundobuffer(size) can limit how many actions are remembered.

Step 5 - Try A Keyboard Shortcut

Start again from the Step 1 file. Add the function and binding before screen.mainloop().

EDIT VIEW - Gray = already there; dark = add or change
artist.forward(LINE_LENGTH)
def undo_last():
    actions_left = artist.undobufferentries()
    if actions_left > 0:
        artist.undo()

screen.onkey(undo_last, 'u')
screen.listen()
screen.mainloop()

Run it. Click the Turtle window, then press and release u once at a time. actions_left stores the number of actions the artist can undo; the if prevents an empty undo. The screen's event loop calls undo_last; you do not call it at the bottom of the file. Undo belongs to this artist's Turtle actions. It does not put an item back into a Python list after pop() or reverse your game's score.

Teacher Check

Draw three lines and undo only the last action. Explain the difference between undo() and clear(). Show why restoring a popped list member would need separate Python code.
