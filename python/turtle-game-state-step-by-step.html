21. Game State: Catch A Falling Ball

The skill tree's Game State skill asks you to name what a game remembers and trace one tick. This lesson grows a small Catcher Game from Keyboard Turtle. A timer schedules each tick so arrow keys remain responsive.

Step 1 - Move The Catcher

Save a new file named catcher.py. Type this whole starter program.

CODE
import turtle

screen = turtle.Screen()
screen.setup(600, 600)
screen.tracer(0)
LEFT_BOUND = -280
RIGHT_BOUND = 280
CATCHER_STEP = 20
CATCHER_Y = -250

catcher = turtle.Turtle()
catcher.shape('square')
catcher.penup()
catcher.goto(0, CATCHER_Y)

def go_left():
    current_x = catcher.xcor()
    next_x = current_x - CATCHER_STEP
    if next_x < LEFT_BOUND:
        next_x = LEFT_BOUND
    catcher.setx(next_x)
    screen.update()

def go_right():
    current_x = catcher.xcor()
    next_x = current_x + CATCHER_STEP
    if next_x > RIGHT_BOUND:
        next_x = RIGHT_BOUND
    catcher.setx(next_x)
    screen.update()

screen.onkey(go_left, 'Left')
screen.onkey(go_right, 'Right')
screen.listen()
screen.update()
screen.mainloop()

Run it. Click the Turtle window, then press and release Left and Right. Names in ALL_CAPS are constants: values we set once as rules for the game. LEFT_BOUND and RIGHT_BOUND leave a 20-unit margin inside the 600-unit window; CATCHER_STEP controls one key press. For example, if current_x is -270, a Left press makes next_x equal -290; the if changes it to LEFT_BOUND, which is -280. Change CATCHER_STEP to 10, run, then restore 20. screen.tracer(0) turns off automatic drawing; each handler calls screen.update() to show its move.

Step 1A - Shorten The Edge Checks

Now that you have seen the if rule work, replace its two lines in go_left() with one line:

EDIT VIEW - Gray = already there; dark = add or change
    next_x = current_x - CATCHER_STEP
    next_x = max(LEFT_BOUND, next_x)
    catcher.setx(next_x)

max returns the larger of its two values. If next_x is -290, max(-280, -290) gives -280, so the catcher stops at LEFT_BOUND. If next_x is -100, the result is -100, so the move is unchanged. The constant makes the rule readable without memorizing what -280 means.

For the right edge, replace its if block with the matching min line:

EDIT VIEW - Gray = already there; dark = add or change
    next_x = current_x + CATCHER_STEP
    next_x = min(RIGHT_BOUND, next_x)
    catcher.setx(next_x)

min returns the smaller value. Predict the results when next_x is 290 and 100, then run and test both edges. Keep these shorter handlers as you build the rest of the game.

Add two more constants below CATCHER_Y, above the catcher setup. They name the ball's starting height and the amount it falls each tick.

CATCHER_Y = -250
BALL_START_Y = 250

catcher.goto(0, CATCHER_Y)
ball = turtle.Turtle()

ball.penup()
ball.goto(0, BALL_START_Y)

def go_left():

Add this function after go_right, before the key bindings.

EDIT VIEW - Gray = already there; dark = add or change
def go_right():
    current_x = catcher.xcor()
    next_x = current_x + CATCHER_STEP
    next_x = min(RIGHT_BOUND, next_x)
    catcher.setx(next_x)
    screen.update()

def tick():
    current_y = ball.ycor()
    next_y = current_y - BALL_FALL_STEP
    ball.sety(next_y)
    screen.update()

Call tick() once after screen.listen(), before screen.mainloop(). Run it: the ball moves down only one small step. Close the window.

Step 3 - Schedule The Next Tick

Add TICK_DELAY_MS = 30 with the other constants, then add one line at the end of tick(). The name records that this delay is measured in milliseconds.

EDIT VIEW - Gray = already there; dark = add or change
BALL_FALL_STEP = 4
TICK_DELAY_MS = 30

catcher = turtle.Turtle()

Now add the timer line.

EDIT VIEW - Gray = already there; dark = add or change
def tick():
    current_y = ball.ycor()
    next_y = current_y - BALL_FALL_STEP
    ball.sety(next_y)
    screen.update()
    screen.ontimer(tick, TICK_DELAY_MS)

Run it. current_y records where the ball is now; next_y is BALL_FALL_STEP lower. The ball keeps falling and arrow keys still respond. ontimer asks the screen to call tick later. The single startup call begins one chain. Do not put a while loop around the Turtle window or call tick() from a key handler.

Step 4 - Add A Catch And A Miss

Add CATCH_RADIUS = 30 and MISS_BOUND_Y = -280 with the constants. The first names how close the ball must be to count as caught; the second names the bottom line where a miss is counted. Before go_left, add the changing state variables score and misses.

EDIT VIEW - Gray = already there; dark = add or change
TICK_DELAY_MS = 30
CATCH_RADIUS = 30
MISS_BOUND_Y = -280

catcher = turtle.Turtle()

Add the state variables after the ball setup.

EDIT VIEW - Gray = already there; dark = add or change
ball.goto(0, BALL_START_Y)
score = 0
misses = 0

def go_left():

Replace the entire tick() function with this version.

CODE
def tick():
    global score, misses
    current_y = ball.ycor()
    next_y = current_y - BALL_FALL_STEP
    ball.sety(next_y)
    distance_to_catcher = ball.distance(catcher)
    if distance_to_catcher < CATCH_RADIUS:
        score = score + 1
        ball.goto(0, BALL_START_Y)
        print('Score:', score)
    elif ball.ycor() < MISS_BOUND_Y:
        misses = misses + 1
        ball.goto(0, BALL_START_Y)
        print('Misses:', misses)
    screen.update()
    screen.ontimer(tick, TICK_DELAY_MS)

Run it. Catch the ball or let it pass. A catch needs the distance to be less than CATCH_RADIUS, not exactly zero. Each event resets the ball to BALL_START_Y so the next tick cannot count the same catch or miss again. global is needed because tick reassigns the two numbers.

Step 5 - Stop At Three Misses

Add MAX_MISSES = 3 with the constants.

EDIT VIEW - Gray = already there; dark = add or change
MISS_BOUND_Y = -280
MAX_MISSES = 3

catcher = turtle.Turtle()

Inside def tick():, find the screen.update() near the end. Replace the screen.ontimer(...) line immediately below it with this branch. Keep the screen.update() line where it is.

EDIT VIEW - Gray = already there; dark = add or change
    screen.update()
    if misses < MAX_MISSES:
        screen.ontimer(tick, TICK_DELAY_MS)
    else:
        print('Game over. Score:', score)

Run it and let three balls fall. The window remains open, but no new tick is scheduled. screen.mainloop() is still the last line of the file.

Step 6 - Send The Ball To A New Place

So far every ball starts at x = 0, where the catcher waits. Give each new ball a random x position. Add import random at the top of the file, above import turtle.

EDIT VIEW - Gray = already there; dark = add or change
import random
import turtle

Remove ball.goto(0, BALL_START_Y) from the initial ball setup. After go_right() and before tick(), add one function for placing a new ball:

CODE
def reset_ball():
    new_x = random.randint(LEFT_BOUND, RIGHT_BOUND)
    ball.goto(new_x, BALL_START_Y)

random.randint picks an x position between the two named bounds. new_x lets you see the choice before the ball moves. In tick(), replace both ball.goto(0, BALL_START_Y) lines with reset_ball().

EDIT VIEW - Gray = already there; dark = add or change
        score = score + 1
        reset_ball()
        print('Score:', score)
    elif ball.ycor() < MISS_BOUND_Y:
        misses = misses + 1
        reset_ball()
        print('Misses:', misses)

Call reset_ball() once at startup, immediately before the existing tick() call. This places the first ball too; keep just one startup call to tick().

EDIT VIEW - Gray = already there; dark = add or change
screen.listen()
reset_ball()
tick()
screen.mainloop()

Run it. Watch several catches and misses. Each new ball starts at the top at a chosen x, so you must steer toward it. A random choice can occasionally repeat the same x. Predict the range of possible x positions and point to the one function that handles every reset.

Step 7 - Trace One Tick

Write down this state before a tick: ball at (0, -226), catcher at (0, -250), score 4, misses 1. next_y becomes -230, then distance_to_catcher becomes 20. Predict the new score and misses; the reset ball's y becomes BALL_START_Y and its x will be somewhere between LEFT_BOUND and RIGHT_BOUND. Trace a miss too: ball starts at (0, -280) and catcher is at (100, -250).

Step 8 - Test The Reset Rule

Make a copy of catcher.py. In the copy, temporarily remove reset_ball() from the catch branch. Run and catch the ball once. Watch the score: it rises more than once while the ball stays close to the catcher. Close the window and restore the reset call. Run again and show that one catch adds only one point.

Now change CATCH_RADIUS from 30 to 20, run, then try 40. Predict which setting makes catching easier and explain why. Restore 30 when done. One change at the top of the file changes the rule wherever the constant is used.
